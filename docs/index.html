node-fetch-sd

Download Soundcloud tracks with Node.js

npm install node-fetch-sd

This package is a fork of soundcloud-downloader, and all documentation can be found at the original repository. The primary difference between the two is that this package can run on a node backend, while the original is designed for use in the browser.
